# Bible Reading Tracker Builder — Help

## Start
Use **Configure** to change the tracker. The page preview updates as you work.
Open **Help** for this short guide.

## Language
- **Interface** changes the tool language.
- **Bible names** changes book names.
- **Auto** follows your browser language.

## Paper
Pick a paper size and direction.
Turn on **Maximize printable area** for the largest clean print.

## Grid
- **Columns**: number of page columns.
- **Chapters / row**: chapter boxes in one row.
- Use sliders for size and spacing.

## Book flow
- **Fixed** keeps a saved layout.
- **Auto balance** spreads whole books across columns.
- **Manual** lets you choose where columns start.

Books are never split between columns.

## Book appearance
Choose fill colors, borders, padding, and rounded corners.

## Text boxes
Change the organization name, challenge title, name line, verse, and reference.

## Edit one book
Click a book in the preview.
Change its title row, chapter rows, row starts, fill, or border.

## Row maps
Click a number to choose where a chapter row starts.
**Auto** measures the book name and chooses a safe start.

## Preview
**Fit preview** changes only the screen view. It does not change print size.

## Save and share
- Changes save in this browser.
- **Export** and **Import** move a config file.
- **Copy share link** puts the config in a link.

## Print
Use **Print**. Check paper size and direction in the print window.


## Special chapter marks

Click a book.
Choose **Special chapter marks**.
Pick a chapter and a mark.
Adjust size, opacity, or vertical nudge if needed.
Positive nudge moves the mark up.
Use **Add / update mark** to save it.
